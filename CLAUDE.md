# CLAUDE.md

## What is this?

A [Perl::Critic](https://metacpan.org/pod/Perl::Critic) policy that lets users define per-project module preferences via an INI config file. Modules can be flagged with a suggested replacement (`prefer`), a human-readable reason (`reason`), and a per-module severity override (`severity`).

**CPAN distribution**: `Perl-Critic-Policy-PreferredModules`

## Repository

- **Upstream**: `cpan-authors/Perl-Critic-Policy-PreferredModules` (branch: `main`)
- **Bot fork**: `Koan-Bot/Perl-Critic-Policy-PreferredModules`
- Build system: [Dist::Zilla](https://metacpan.org/pod/Dist::Zilla) (`dist.ini`, `weaver.ini`)
- Minimum Perl: **5.12** (due to `Mixin::Linewise` dependency)

## Architecture

Single-module distribution:

- `lib/Perl/Critic/Policy/PreferredModules.pm` — the policy implementation
- `t/00-load.t` — basic load test
- `t/check-policy.t` — functional tests (config parsing, violations, severity, error handling)

### How it works

1. User adds `[PreferredModules]` to `.perlcriticrc` with a `config = /path/to/file.ini`
2. `initialize_if_enabled()` reads the INI file via `Config::INI::Reader`
3. `_parse_config()` validates keys against `optional_config_attributes` (currently: `prefer`, `reason`, `severity`)
4. `violates()` checks each `use`/`require` statement against the config and returns violations

### Config INI format

```ini
[Do::Not::Use]
prefer = Another::Package
reason = "Please use Another::Package"
severity = 5

[Discouraged::Module]
```

Each `[Section]` is a module name. All keys are optional.

## Conventions

- Perl 5.12+ syntax only — no features from later versions
- Tests use `Test2::V0` (imported as `Test2::V0`, declared as `Test2::Bundle::Extended` in cpanfile for historical reasons)
- Tests use `File::Temp` for temporary files — not `Test::MockFile`
- Error propagation via `Perl::Critic::Exception::Configuration::Generic->throw()`
- POD is generated by `Pod::Weaver` during dist build

## CI

GitHub Actions workflow (`.github/workflows/testsuite.yml`):
- `ubuntu` job: latest Perl on ubuntu-latest
- `linux` matrix: Perl 5.12–5.34 in `perldocker/perl-tester` containers (run as root)

**Root caveat**: Docker container tests run as root, so `chmod`-based permission tests must be skipped with `$> == 0`.
